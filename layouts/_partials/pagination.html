{{- /* Server-rendered content pagination. Context: paginator — a Hugo paginator truncatedFrom — optional true element count when the caller capped the page set (0 = not capped) Every control is a real to a paginator URL, so pages stay crawlable and shareable. Number windowing matches the sidebar mini-pager: page 1, current ±1, last, with … wherever the run skips. The cap for very large corpora (decision D1) is applied by the *caller*, which truncates the slice before paginating. That is what actually bounds the build: capping only the links here would still let Hugo generate every pager page. This partial just reports the cap. */ -}} {{- $paginator := .paginator -}} {{- $truncatedFrom := int (.truncatedFrom | default 0) -}} {{- $cur := $paginator.PageNumber -}} {{- $total := $paginator.TotalPages -}} {{- $capped := gt $truncatedFrom $paginator.TotalNumberOfElements -}} {{- if gt $total 1 }} {{- $want := slice -}} {{- range (slice 1 (sub $cur 1) $cur (add $cur 1) $total) -}} {{- if and (ge . 1) (le . $total) -}}{{- $want = $want | append . -}}{{- end -}} {{- end -}} {{- $want = $want | uniq | sort -}}
